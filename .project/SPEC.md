# Stamp Tool 顶层规格

## 产品定位
桌面端文档盖章工具，支持多种文档格式的印章添加、位置调整、预览和导出。

## 核心功能
1. 文件选择：支持 PDF、图片（PNG/JPG/BMP/TIFF）、Excel 文件；Word 适配后新增 DOCX（本地转换路线，见下）
2. 印章管理：选择印章图片、调整大小、透明度、旋转角度
3. 页面预览：多页文档的翻页预览
4. 位置调整：拖拽或输入坐标定位印章
5. 批量导出：生成带印章的新文件

## Word（DOCX）支持边界（2026-09-14 P1.3 同步）

- **输入**：`.docx`（含大写扩展名）。`.doc`、`.docm`、原生 `.wps` 不支持；加密文档不做密码输入，提示在原软件处理后导出 PDF。
- **转换**：不内嵌排版引擎。调用本机已安装的 LibreOffice / Microsoft Word / WPS 作为可替换转换后端，探测可用性、引擎选择带偏好记忆。探测只是便利层、可能遗漏（自定义目录/每用户安装）：⚙ 设置的引擎页提供「手动指定安装目录」（优先级最高）与「下载内置 LibreOffice 组件（约 300–360MB，装于 ~/.stamp_tool/drivers，用户自行决定，官方源+SHA-256 校验）」。无可用引擎或接口不可用时提供「手动导出 PDF 后拖入本工具」路径。不上传文档。
- **输出**：DOCX 一律输出 `原文件名-已盖章.pdf`，保留原始 Word 文件；可编辑 DOCX 输出不在当前版本范围。
- **一致性**：预览与盖章基于同一份转换 PDF 快照，坐标只关联该快照；重新转换后印章位置需重新放置。不承诺不同引擎/字体环境分页完全一致。
- **执行细节、平台结论与测试规格**：`.project/plans/word-support/`（spec/design/dod/compatibility）。

## 非功能需求
- 单文件处理，暂不支持批量多文件
- 中文 UI
- 跨平台：macOS、Windows
- 独立可执行文件分发
