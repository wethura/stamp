| A02 | 跨页表格/合并单元格/页眉页脚/横竖页 | 🤖 mixed-layout：2 页 + 横向节尺寸翻转（已通过） | 👨 截图核对表格不截断、页眉页脚位置 |
| A03 | 多章/旋转/透明度/边缘放置，预览与导出同源 | 🤖 复用既有导出一致性测试（PDF 路径）扩展到快照来源 | 👨 144 DPI 渲染边界误差 ≤2 像素抽查 |
| A04 | 缺字体/中文空格长路径/只读源目录 | 🤖 长路径+中文文件名样本；只读目录（chmod 555）转换工作副本不受影响 | 👨 缺字体机器上核对替换记录，不静默丢字 |

| A06 | 取消/超时/连续导入 A 与 B/关闭应用 | 🤖 桩引擎 + cancel_token：过期结果不覆盖新会话；超时归类 timeout | 👨 GUI 取消按钮时序（≤1s 恢复） |

| A08 | Word/WPS 共存，指定引擎，更换引擎 | 🤖 偏好记忆与快照切换逻辑（单元）；换引擎后清空章位置 | 👨 真实双引擎机器上手动切换 |
| A09 | 断网/个人企业版/未登录 | ⏸ 待多环境 | 👨 断网跑 LibreOffice（应正常）+ 记录 Word/WPS 授权条件 |
| A10 | macOS 授权拒绝/恢复；打包 .app | ⏸ 打包后 | 👨 TCC 拒绝→错误文案→系统设置恢复→重试成功；.app 真实包 |

| A12 | 回归 PDF/图片/Excel/印章库 | 🤖 全量既有测试套件（当前 79 项）随 CI/提交跑 | 👨 抽查 GUI 主流程 |

## P2 前必须先落地的自动测试（TDD 起点）

1. `test_docx_precheck.py`：zip 头校验——合法 docx 通过；corrupt/加密/纯文本拒绝并分类（A04/A05 防线）。
2. `test_conversion_service.py`：桩引擎状态机——探测缓存、偏好记忆、取消、超时、过期结果丢弃、临时目录清理（A06/A08 自动化核心）。
3. `test_word_handler.py`：WordHandler 注册两处、输出过滤器（`原文件名-已盖章.pdf`）、委托 PDFHandler 后页数/尺寸与快照一致（A11）。
4. 既有 `test_word_probe.py` 保持通过。
